# MovieTrack
Building a movie-tracking application for a movie enthusiast who wants to maintain and share a personal collection. Users must be able to search by cast, director and genre; view third-party ratings; submit one personal rating per movie; and receive AI-assisted search results and recommendations.

## Project Structure

- `backend/` - API and server-side application
- `frontend/` - User interface
- `docs/` - Project documentation
- `.github/workflows/` - GitHub Actions workflows
